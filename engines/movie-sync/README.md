# Movie Sync

Player codec for film-timed looks. Content is **not** bundled — install from
[OpenRGB3DSpatialPresets](https://github.com/Wolfieeewolf/OpenRGB3DSpatialPresets)
into the plugin data root:

```text
movie-sync/
  catalog.json
  effects/<category>/*.action.json
  vlc/
```

Authoring notes and the VLC helper live in that presets repo under `movie-sync/`.
